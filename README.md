# MOCHI Website - Premium Landing Page

A completely fresh, independent MOCHI website built from scratch.

## Project Overview

This is a **brand-new, standalone MOCHI website** — not a redesign, continuation, or modification of any previous MOCHI project. The website is built independently with its own codebase, design system, and configuration.

## Design Philosophy

- **Premium Cinematic Aesthetic**: Dark theme with gold accents, inspired by high-end visual design
- **3D-Inspired Visuals**: Cinematic lighting, volumetric effects, and character showcases
- **Polished Animations**: Subtle transitions and micro-interactions throughout
- **Responsive Layout**: Works beautifully from mobile to desktop

## Key Features

- **Hero Section**: MOCHI character showcase with premium typography
- **About Section**: Information about the MOCHI universe and gameplay
- **Game Section**: Overview of mechanics and features
- **Features Section**: Cinematic lighting, polished animations, progression system, worlds & biomes
- **Roadmap Section**: Multi-phase development plan
- **Social Links**: X and Telegram only (as specified)

## Technical Details

- **No Framework**: Pure HTML5, CSS3, and vanilla JavaScript
- **No Dependencies**: No external CSS frameworks, no jQuery, no build steps
- **Font Loading**: Fraunces (serif headlines) + Inter (sans-serif body) from Google Fonts
- **Responsive**: Mobile-first approach, adapts from 320px to 1400px+
- **Accessibility**: Semantic HTML, keyboard navigable, prefers-reduced-motion support
- **Performance**: Critical CSS inlined, no render-blocking resources

## Independence Guarantees

✅ Completely separate codebase — no code shared with previous MOCHI project  
✅ Fresh design system — custom colors, typography, and layout  
✅ Independent dependencies — only Google Fonts CDN, no npm/packaging needed  
✅ Clean social configuration — only specified X and Telegram links  
✅ No connection to old deployment, backend, or infrastructure  
✅ New Git repository recommended (not connected to any prior repo)  
✅ All assets are newly created or officially provided MOCHI character assets only  

## Getting Started

1. Open `index.html` in any modern browser
2. No build step required — files can be served statically
3. Customize content, colors, or layout as needed
4. Deploy to any hosting platform (Vercel, Netlify, GitHub Pages, etc.)

## Deployment

The website is designed to be deployed independently. Recommended platforms:
- Vercel (recommended for static sites)
- Netlify
- GitHub Pages
- Any web host with static file serving

No environment variables, API keys, or backend configuration required.

## Development

To make changes:
- Modify `index.html` for structure and content
- Edit `css/style.css` for styling and design updates
- Update `js/app.js` for interactivity changes

All changes are contained within this project directory and do not affect any other MOCHI projects.
